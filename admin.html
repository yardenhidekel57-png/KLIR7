חיבור ללוח

ההודעות שנכתבות כאן נשמרות ישירות בתוך ה־GitHub repository שממנו מתפרסם הלוח הדיגיטלי, בקובץ בשם notices.json שיושב באותה תיקייה כמו index_he.html. את הפרטים הבאים ממלאים פעם אחת בלבד, בדרך כלל מי שהקים את הלוח — לאחר מכן שאר חברי הוועד פשוט פותחים את העמוד הזה ורואים ישר את מסך ניהול ההודעות.

מומלץ ליצור טוקן מסוג Fine-grained המוגבל ל־repository הזה בלבד, עם הרשאת Contents: Read and write ותו לא — כך שגם אם הטוקן ייחשף, הנזק האפשרי מוגבל לתיקייה הזו בלבד. הטוקן נשמר רק בדפדפן הזה (לא נשלח לשום מקום מלבד GitHub עצמו).
